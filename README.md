# BoxeTrainer

## Pré-requisito

Tenha o [Node.js](https://nodejs.org/) instalado.

## Windows (PowerShell)

```powershell
cd box-game
npm start
```

## Linux (Ubuntu)

```bash
cd box-game
npm start
```

Depois, abra no navegador:

http://localhost:3000

Permita o acesso à câmera quando solicitado.
